## How to run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) validates `news.png`
(PNG magic, ≤1 MiB, ≤1024×1024) and copies it byte-for-byte to
`$MAKEFUN_OUTPUT_DIR/entry.png`, printing its sha256. Both runs write
identical bytes.
